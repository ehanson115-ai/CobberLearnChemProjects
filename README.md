# CobberLearnChemProjects
Projects for Foundations of Machine Learning for Chemistry.  

AlkaneBoilingPoints: This simple code plots the number of carbon atoms in the alkane on the x-axis and the boiling points of that alkane on the y-axis. It generates a properly labeled graph using Matplotlib.  
    
PubChemFetcher: This Python script uses PubChemPy to fetch and display key chemical properties for any compound by name. It retrieves the following descriptors: Molecular Formula, Molecular Weight, SMILES string, Topological Polar Surface Area (TPSA), and Heavy Atom Count. The output is formatted neatly for easy reading. The script is reusable for any compound, and can be run interactively to analyze multiple compounds without editing the code.  
  
MoleculeExplorer: his Python script allows users to input one or more SMILES strings and calculates key chemical properties for each molecule using RDKit. Properties include: Exact Molecular Weight, Hydrogen Bond Donors, Topological Polar Surface Area (TPSA), Total number of atoms, Number of bonds, Number of rings, Number of rotatable bonds, The program outputs results in a clean, easy-to-read table and supports analyzing multiple molecules easily from a SMILES string and molecules name inputted by a user.  

MakingDataWhole: This script loads the Titanic dataset, handles missing ages using mean imputation, manual KNN imputation, and manual linear regression, and analyzes feature relationships with a correlation matrix. It generates plots showing actual versus predicted ages and outputs a comparison table of average age and mean absolute error (MAE) for each method. The results help evaluate which imputation method best estimates missing ages.  
  
ErrorMetrics: This Python code analyzes the performance of a predictive model by comparing actual and predicted values. It calculates key error metrics—mean absolute error (MAE), mean squared error (MSE), and R², both manually using NumPy and by validating with scikit-learn functions. The code also displays a table of actual, predicted, and residual values, and generates two visualizations: a predicted vs. actual scatter plot with square markers and a residuals plot with a twist of pink star markers. The worst prediction is highlighted in red in both plots, and the residuals plot uses a custom font for the title and axis labels. These metrics and plots allow the user to evaluate model accuracy, identify the largest errors, and visually assess patterns in the predictions.  

ElementClustering: This model explores patterns in Group 1 (alkali metal) elements by reading their atomic data from a CSV file and applying K-Means clustering based on atomic radius and first ionization energy. The data is first printed to the screen so the user can confirm it loaded correctly, then the user chooses how many clusters to create. The results are shown in a matplotlib scatter plot where each element is colored by its cluster, labeled with its chemical symbol, and the cluster centers are marked with small green Xs. Personalized changes include adding meaningful cluster names (“Lighter Alkali Metals” and “Heavier Alkali Metals”) when using two clusters and adjusting the plot styling to make the visualization clearer and easier to interpret. 
  
GradientDescent: This project generates noisy linear data and fits both a linear regression and a quadratic polynomial regression to it. The program visualizes the noisy data, the true line, and both fitted models, allowing users to manually enter coefficients to calculate the mean squared error (MSE). Two separate loss landscapes are generated: one for the linear model (slope vs intercept) and one for the polynomial model (quadratic vs linear coefficient), showing visually where low-error regions occur in yellow and high-error regions in purple. The results demonstrate how the models approximate how the error changes across different parameter choices, providing insight into model fitting and optimization.  

Weasel: This program simulates evolution in a simple way to gradually “evolve” any phrase you enter. It starts with a completely random string and repeatedly makes small random changes to the phrase. In each generation, it creates 100 new versions of the string and keeps the one that matches the target phrase the best. Over time, more and more letters become correct until the full phrase is reached. The program also tracks how the score improves over generations, creates a graph showing that progress, and automatically saves the graph in the Weasel folder.  

ArtificialNeuralNetwork: This project compares two models for predicting the boiling points of compounds based on their molecular weights: a simple linear regression and a neural network. The dataset includes 11 compounds with their molecular weights and boiling points. The code trains both models, evaluates their performance using metrics like MAE, MSE, and R squared, and creates plots to visualize predictions, residuals, and model comparisons. The project includes two interactive features: users can enter a molecular weight to see predicted boiling points from both models (my added twist on the project), and they can experiment with different neural network architectures by choosing the number of layers and neurons per layer.

Convolution: This program demonstrates how convolutional filters are used in image recognition, similar to the way convolutional neural networks (CNNs) analyze images. First, a simple 5×5 black-and-white image of a plus sign is created using a NumPy array, where 1 represents the foreground and 0 represents the background. A 3×3 horizontal edge detection filter is then applied to the image using the convolve2d function from SciPy. The result is a feature map that highlights areas where horizontal edges appear in the image. The program also visualizes the input image and the feature map using Matplotlib. To extend the demonstration, the same filter is applied to simple Roman numeral patterns to show how different shapes produce different feature responses depending on the types of edges present.  

ImageClassifier: This project uses the pre-trained VGG16 convolutional neural network to classify images of everyday objects. The code loads multiple images, preprocesses them to the required 224×224 pixel format, and predicts the top 5 object classes with confidence scores. By analyzing raw pixel data through multiple layers, the CNN transforms simple features like edges and corners into complex object representations, enabling meaningful predictions. This process is analogous to how chemists interpret spectral or visual data to deduce molecular structures, turning raw measurements into scientific insights.  

QLearning: This project implements a Q-learning agent to solve the FrozenLake environment from OpenAI Gymnasium. The agent learns to navigate slippery ice, avoid holes, and reach the goal by updating a Q-table based on its experiences. During training, the agent balances exploration and exploitation, gradually improving its decisions, which is visualized through a learning curve and a policy map of directional arrows. This project taught me how reinforcement learning allows an agent to learn from trial and error, turning raw feedback into meaningful strategies. This is similar to how chemists interpret experimental data to draw conclusions from observations.  

CartPole: The CartPole environment is similar to the CobberTitrator because both follow the same reinforcement learning cycle of state --> action --> reward --> new state, but they differ in context and complexity. CartPole focuses on balancing a physical system, while CobberTitrator models a chemical titration process. In both systems, random action selection leads to poor and inconsistent performance, as shown by the low average reward of about 22 steps in the random CartPole trials. The rule-based approach improved performance to an average of about 43 steps, proving that even a simple strategy can significantly outperform randomness. However, the Q-learning agent showed only slight improvement in this short training period, with an average of about 24 steps in the final episodes, thus displaying the variability and stochastic nature of reinforcement learning. This variability reflects how outcomes depend on exploration and randomness, similar to early training in the CobberTitrator. With more training, the Q-learning agent would be expected to improve further and outperform both random and rule-based approaches.   
  
CaliforniaHousing: This project analyzes and predicts housing prices using the California Housing dataset. Multiple regression models, including Linear Regression, Decision Tree, Random Forest, and Support Vector Regression, were trained and compared, with Random Forest performing the best due to its ability to capture complex, nonlinear relationships. The analysis revealed that median income is the strongest predictor of housing prices, while location also plays a significant role, reflecting real-world real estate trends. Through this project, I learned how to build, evaluate, and compare regression models, visualize data patterns, and make meaningful predictions from real-world data. The file called housing_gui.py includes a graphical user interface (GUI) built with Tkinter that allows users to input housing characteristics and receive instant price predictions after being trained. The interface includes default values, input validation, tooltips explaining each feature, and a "clear" button to reset inputs. This makes the model accessible to users without programming experience and demonstrates how it can be turned into an interactive, real-world tool.  

Clustering: This code applies K-means clustering to the Iris dataset using scikit-learn to identify patterns in flower measurements without using species labels. The model groups flowers based on sepal and petal dimensions, then compares the resulting clusters to the actual species to evaluate accuracy. Also, it generates a 3D graph based on sepal length, petal length, and petal width. Users can also input the number of clusters to make it more interactive. Through this project, I learned that unsupervised learning can uncover meaningful structure in data even without prior labels, but the results are not always perfectly aligned with real categories. This connects to chemical data analysis, where models can detect patterns such as hydrogen bonding or solubility trends based only on numbers given. It helps scientists identify relationships that may not be immediately obvious.
